# Frontend Layer

This directory represents the frontend layer in the working architecture.

The live implementation remains in `src/frontend` and `src/app` because the app is built on Next.js and the route handlers must stay in the App Router structure for proper runtime behavior.

## Current mapped sources
- UI components: `../src/frontend/components`
- Hooks: `../src/frontend/hooks`
- Client state: `../src/frontend/store.ts`
- App shell: `../src/app/layout.tsx`, `../src/app/page.tsx`
